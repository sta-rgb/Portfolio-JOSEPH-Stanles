# PROJET_INFO_S1
Binevenue, ceci est le read me de notre projet space miner, ici vous trouverez la procédure expliqué point par point de comment lancer le jeu une fois qu'il a été téléchargé en .zip puis extrait sur votre ordinateur. 
Commençons donc notre tutoriel d'ouverture:
-Etape 1, ouvrir le fichier space miner 
-Etape 2, Cliquer sur "LANCER_SPACE_MINER" ou alors "LANCER_SAPCE_MINER.bat" pour lancer la compilation vérification du code 
-Etape 3, Si tout fonctionne après votre extraction, vous pouvez jouer dès la fin de la compilation. Sinon, vous  devez re-décompresser le fichier space miner dans un autre fichier ou sur votre bureau.
